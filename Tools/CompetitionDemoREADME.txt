《影韵》Windows x64 独立 Demo
=============================

运行方式
1. 将整个压缩包解压到本地文件夹。
2. 双击 YingYunDemo.exe。
3. 内置曲目为《象王行》和《青玉案》；选择曲目后选择简单、普通或困难。

不要只复制 exe。YingYunDemo_Data、MonoBleedingEdge、UnityPlayer.dll 和其余 DLL 都必须与 exe 保持原有相对位置。

自定义歌曲
- 在选曲页点击“打开歌曲文件夹”。
- 放入 MP3、FLAC 或 WAV 后点击“刷新歌曲”。
- 首次分析可能需要等待，生成的数据保存在当前 Windows 用户目录中。

问题回报
1. 在选曲页点击“运行日志”。
2. 点击“复制完整日志”后，将文字直接发给开发者；或点击“打开日志文件夹”，发送 YingYun-latest.log。
3. 请同时说明发生问题前选择的曲目、难度和操作步骤。

支持环境
- Windows 10 / Windows 11 64 位
- 建议使用支持 DirectX 11 的显卡及已更新的显卡驱动
- 不需要安装 Unity、Python 或节拍分析工具
- 自定义歌曲分析所需的 Visual C++ x64 运行库已随 Demo 采用应用本地方式提供
- Demo、歌曲及日志路径可包含中文字符

若 Windows SmartScreen 显示未知发布者，请先确认压缩包的 SHA-256 与随包校验文件一致。此测试版尚未进行代码签名。
