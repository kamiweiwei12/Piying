## 绘制规格（请照这个交付）

1. **PNG-24，透明背景**，一片一张，不要拼成图集（图集由程序侧处理）。
2. 文件名照 `分片规格表.csv` 的「建议文件名」栏，例如 `puppet_torso.png`、`puppet_robe_skirt.png`。
3. **尺寸按 400 px / 世界单位**换算，也就是照 CSV 里的「作者像素」栏。
4. **轴心一律取图片正中心**（0.5, 0.5），与程序一致；不要为了对位而偏移画布。
5. **不要预先旋转**。冠翅的 ±12°、四肢的角度都由程序套用。
6. **角色面向右侧**绘制（侧脸鼻朝 +X）。左侧由程序水平镜像，所以左右两侧共用同一张图。
7. 边缘多留 **2–3 px 余量**，关节处旋转时不会露底。
8. **不要烘焙投影**。阴影来自程序层的背光与纸幕，画上去会重复。
9. 建议同时给一份 PSD/AI 源文件与 2× 版本，方便以后改角色。

## 结构与动态约束

- 关节层级：骨盆（根）→ 腰 → 颈 → 头冠；腰 → 左右肩 → 肘 → 腕 → 手掌扇；骨盆 → 左右髋 → 膝 → 踝。
- 会大幅转动：肩、肘、腕、髋、膝、踝、腰、颈。
- 只沿长轴旋转：上臂 0.82、前臂 0.72、大腿 0.88、小腿 0.82 世界单位。
- **躯干与下裳会被镜像**（`localScale.x = ±1`，转身动作），所以袍身、冠饰不要有明确的左右不对称文字或单向光影。
- 水袖拖尾会随惯性摆动，建议拆成 2–3 层或可变形网格。
- 六根竹杆分别拉：左腕、头、右腕、左踝、胸前杆座、右踝；美工只要保证这些接点周围留出缝线空间。

## 风格建议（灰盒已经暗示的方向）

- 皮料主体用深红棕（现在是 `0.12, 0.025, 0.018`），装饰线用暖橙红（`0.70, 0.12, 0.045`）。
- 皮影的关键特征是**半透明皮料 + 镂空纹样 + 暖色描边**，装饰片可以画成镂空花格，比实心色块更像皮影。
- 胸口镂空与水流袖现在带透明度，美术可以放大这个特征。
- 细节标准：**在 1080p 下角色只有 176 × 440 px**，所以花纹要在整幅缩到四分之一后仍然看得清，不要画过细的线。

## 不用重画的部分

- 关节端帽与铆钉由程序生成，只要确认颜色与皮料协调。
